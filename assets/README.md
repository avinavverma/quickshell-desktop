# assets

Copies of things on the original PC that `setup.sh` restores:

| File | What | Source / licence |
|---|---|---|
| `icons/Mkos-Big-Sur-Night.tar.xz` | The icon theme in use (unpacked to `~/.local/share/icons`) | "Mkos-Big-Sur" by zayronxio, GPL-3.0 — https://github.com/zayronxio/Mkos-Big-Sur, https://store.kde.org/p/1400021 (the *Night* variant came from the KDE Store) |
| `wallpaper.jpg` | The desktop wallpaper (`10-14-Night-6k.jpg`) | the user's own download |
| `keyd/default.conf` | keyd key swaps: Right Alt ↔ left Super, PrtScr ↔ Insert (for this laptop's keyboard) | the user's own config |

(`wallpaper-dialogs/wallpaper.jpg` is a different image — the one the floating dialogs belong to.)
